Custom WordPress theme for Novira Academy – a multi-department educational institution.

== Description ==

Novira Academy is a custom WordPress theme designed for a multi-department educational institution offering:

* **Education & Professional Development** - Language courses, technology training, and professional development programs
* **Certified Translation Services** - Professional translation services for documents and official papers
* **American Diploma Programs** - American curriculum diploma programs with Cognia accreditation

The theme is built with a trust-first philosophy, prioritizing real content and authentic representation of the institution. It features:

* **Modular Template Parts** - Reusable components for consistent design
* **RTL Support** - Full right-to-left language support for Arabic
* **Mobile-First Design** - Responsive layout starting from mobile viewports
* **Customizer Integration** - Easy customization of colors, contact information, and social media links
* **Accessibility Features** - WCAG 2.1 AA compliance considerations
* **Performance Optimized** - Lightweight code with optimized assets

== Installation ==

1. Upload the `novira-academy` folder to the `/wp-content/themes/` directory
2. Activate the theme through the 'Themes' menu in WordPress
3. Go to Appearance > Customize to configure theme settings
4. Set up your menus under Appearance > Menus
5. Add your content using the provided page templates

== Customization ==

The theme provides the following customization options through the WordPress Customizer:

* **Contact Information** - WhatsApp number, email, phone, address
* **Social Media** - Facebook, Instagram, TikTok, YouTube URLs
* **Theme Colors** - Primary and secondary color customization
* **Hero Section** - Badge text, title, and subtitle
* **Footer Settings** - Copyright text

== Page Templates ==

* **Front Page** - Homepage template with hero, departments, and trust sections
* **Department** - Template for individual department pages
* **About** - About page template
* **Contact** - Contact page template with form and map
* **Services** - Services overview page template

== Widgets ==

The theme includes the following widget areas:

* **Sidebar** - Main sidebar widget area
* **Footer Column 1** - First footer column
* **Footer Column 2** - Second footer column
